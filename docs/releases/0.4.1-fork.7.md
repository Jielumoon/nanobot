# v0.4.1-fork.7

基于 `v0.4.1-fork.6`，整合命令后台任务、MCP 后台等待和按会话动态发现。沿用 Fork 发布惯例，Python 包版本保持 `0.4.1`。

- `exec` 支持后台执行，使用 `exec_session` 读取结果或取消本地任务，完成事件可唤醒原会话接续。
- MCP 工具通过 `_nanobot_background` 复用后台生命周期、原权限和连接；T3 等待固定 thread/run，使用独立等待预算，不重发启动或发送请求。本地取消不代表远端任务停止，普通 MCP 返回也不代表远端任务完成。
- 初始仅暴露内置工具和 `mcp_search`；搜索加载后，下一次模型请求携带命中工具的准确 schema，包括后台入口。加载状态按会话持久化，压缩请求同步过滤工具定义，未加载工具不能绕过调用限制。

本地 19 项核心检查通过，包含真实 MCP SDK 与 mock 模型的发现、加载、后台完成和原会话接续检查。尚未验证真实 T3、HTTP 或微信投递。

本次发布产物为包含 WebUI 的通用 Python wheel，不包含原生 TUI；不提供上游签名更新元数据。
